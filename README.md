# Sadi Abbas — Business Technology & AI Solutions Portfolio

Live portfolio: https://sadiabbas1122.github.io/sadiabbas1122/

A responsive, client-facing portfolio covering business operations, AI automation, lead research, virtual assistance, social media operations, web and app projects. Includes service filters, a project enquiry planner, package formats and a mailto-based contact form.

## AI Business Chatbot MVP

Source: [ai-chatbot](./ai-chatbot/)

This is a separate single-business pilot built with a static chat interface and a Cloudflare Worker backend that calls Gemini using a server-side secret. The chatbot is not live until a Cloudflare Worker is deployed and configured with a Gemini API key, approved business information and allowed website origins.

See [chatbot setup instructions](./ai-chatbot/README.md).
